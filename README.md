# Araç Envanter Frontend

Araç envanter ve bakım/tamir takip sisteminin Türkçe web arayüzüdür.

## Planlanan ekranlar

- Admin girişi
- Kontrol paneli
- Araç envanteri
- Araç detayları
- Bakım ve tamir kayıtları
- Bakım uyarıları
- Excel raporları
- Şirket, birim ve admin ayarları

Frontend, backend API temeli tamamlandıktan sonra Next.js ve TypeScript ile geliştirilecektir.
